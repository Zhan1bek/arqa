# ADR-0004. Стек: TypeScript-монорепо с общим доменным пакетом

**Статус:** принято

## Решение

- `packages/core` — чистая доменная логика без I/O: схема и валидация поездки, расчёт сводки,
  работа с датами, форматирование денег. Её используют и сервер, и клиент, поэтому правила
  валидации живут в одном месте.
- `apps/server` — Fastify 5 и SQLite через встроенный `node:sqlite` (Node ≥ 22.13). Нет нативной
  сборки, которая ломается на Windows и в CI, а ограничения уникальности при этом настоящие.
- `apps/mobile` — Expo (React Native): одна кодовая база для Android/iOS (через Expo Go)
  и веба (для демо и скриншотов).
- Тесты — Vitest; API тестируется через `fastify.inject`, без поднятия порта.

## Почему не проще

Консольный клиент закрыл бы задание быстрее, но вакансия про мобильные приложения, а
довести изменение «до телефона водителя» — часть проверки.
