# /verify

1. Запусти `npm run check`. Если упало — почини причину (не ослабляй проверку) и повтори.
2. Смоук API:
   - запусти в фоне `PORT=3998 DB_PATH=":memory:" npm run start -w @diary/server`;
   - дождись ответа `curl -s localhost:3998/health`;
   - `curl -s localhost:3998/api/days/2026-10-01` — в сводке должны быть
     `trips: 2, revenue: 3900, commission: 585, net: 3315`;
   - останови сервер.
3. Если менялся `apps/mobile`: `npx expo export --platform web` в `apps/mobile` должен
   собраться без ошибок.
4. Коротко отчитайся: что запускал и что получилось. Если какой-то шаг пропущен, скажи об этом прямо.
