## Claude Code: специфика

Общие правила — в AGENTS.md выше (его же читает Codex). Здесь только то, что относится к Claude Code.

- **Сабагенты** (`.claude/agents/`):
  - `test-writer` пишет тесты по критериям AC-* из SPEC до реализации и не трогает прод-код;
  - `reviewer` — независимое ревью диффа против SPEC, ADR и инвариантов, только чтение;
  - `api-qa` поднимает сервер и проверяет критерии приёмки живыми HTTP-запросами.
- **Скилл** `/verify` — полная проверка перед коммитом: `npm run check` плюс смоук API.
- **Хук** `PostToolUse` форматирует изменённый файл Prettier'ом (`.claude/hooks/format.mjs`),
  поэтому в диффах нет шума от форматирования.

Порядок работы над фичей: план → `test-writer` (красные тесты) → реализация → `/verify` →
`reviewer` в свежем контексте → правки → коммит.
